# RouterLens tools

The current eight read-only tool contracts are maintained in [tool-contracts.md](tool-contracts.md). The official OpenRouter MCP supplies model/provider discovery, benchmark evidence, generation lookup, documentation, and its own balance tool.

In the default 0.3.1 compatibility package, only the official MCP is connected. RouterLens private account tools require a separately authenticated private bridge and remain unavailable through the default package until the hosted authentication acceptance gates pass.

See [acceptance.md](acceptance.md) for the ten original MVP scenarios and their current evidence/remaining gates, and [self-host.md](self-host.md) for credential-free validation.
